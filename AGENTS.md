# Arto — руководство для ИИ-помощников (Codex, Claude и др.)

Arto — локальное приложение для художников: генерация эскизов в духе Midjourney,
редактирование картинок словами (аналог Nano Banana) и простой редактор (выделение, лассо, кисть…).
Работает **офлайн и бесплатно** на видеокарте пользователя. Пользователи — художники, не технари:
интерфейс должен оставаться простым, на русском, без технических терминов.

## Как устроено

```
server.js            HTTP-сервер (Node.js, без фреймворков), задания, очередь видеокарты, API
comfy.js             связь с ComfyUI (скрытый «двигатель») + графы: генерация (+ControlNet, LoRA, стиль с картинок),
                     апскейл, редактирование, раскрытие кадра (wfOutpaintUnion), обучение манеры (wfTrainLora)
prompt.js            стили-техники, «эстетический слой» (stylize/chaos/weird), разбор --параметров
translate.js         офлайн-перевод русского промпта на английский (NLLB + «словарь художника», папка models/)
facefix.js           поиск лиц (YOLO, models/face, onnxruntime-node) для «Исправить и увеличить» — перерисовка лица крупно
texture.js           сохранение фактуры: после правки ИИ возвращает оригинальные мазки там, где ничего не менялось
update.js            автообновление с GitHub (VERSION), data/ и модели не трогает
atelier.config.json  редакция (pro/lite), путь к ComfyUI, какие модели использовать
public/index.html    разметка
public/style.css     дизайн (цвета — переменные в :root)
public/app.js        лента, «Мои работы», просмотр, рисование, страница «Мой стиль»; правка словами — в редакторе (editor.js)
public/editor.js     ядро редактора: холсты, маска выделения, история, панель, ИИ по выделению
public/paints.js     «Палитра и краски»: цвета картинки → тюбики и рецепты смесей, «Мои тюбики»
public/data/paints.json  серии красок: Невская палитра, Малевичъ, Гамма (номера и цвета с сайтов производителей)
public/tour.js       «Как пользоваться»: пошаговые подсказки по каждой возможности (подсветка кнопки + текст + пример)
public/tour/         картинки-примеры «до → после» для подсказок
public/tools/*.js    инструменты редактора — КАЖДЫЙ ФАЙЛ = ОДИН ИНСТРУМЕНТ, подхватываются автоматически
data/                работы пользователя (gallery.json, images/, boards.json, loras.json, prompts.json,
                     local.json — настройки этого ПК) — не коммитить, не передавать
```

ComfyUI запускается сервером сам (`comfy.js → ensureRunning`), пользователь его никогда не видит.
Закрыли все окна Arto — сервер сам выключается вместе с ComfyUI (`/api/alive`, `/api/bye`, `checkWindows`).
Для проверок разработчика: `ARTO_KEEP=1` — не выключаться без окон, `ARTO_COMFY_URL=http://127.0.0.1:8199` — свой двигатель,
`PORT=7790` — свой порт (чтобы не мешать запущенному у пользователя Arto и его двигателю).
Нет сборки и бандлера: правите файл → обновляете страницу (для server.js — перезапуск `start.bat`).

## Как добавить инструмент редактора

Создайте файл `public/tools/NN-имя.js` (NN — порядок на панели). Он появится сам, ничего регистрировать в других местах не нужно.

```js
(() => {
  Editor.register({
    id: 'blur',                 // уникальный id
    name: 'Размытие',           // подпись на панели (коротко, по-русски)
    key: 'r',                   // горячая клавиша (необязательно)
    order: 80,                  // место на панели
    hint: 'Подсказка для художника — что делает инструмент.',
    icon: '<svg viewBox="0 0 24 24">…</svg>',  // 24×24, stroke=currentColor

    // Вариант А — разовое действие (кнопка): только action
    // action(ed) { … ed.commit(newCanvas, 'Готово'); },

    // Вариант Б — инструмент с настройками и работой мышью:
    options(panel, ed) { panel.insertAdjacentHTML('beforeend', '<label class="ed-field">…</label>'); },
    activate(ed) {}, deactivate(ed) {},
    down(p, e, ed) {}, move(p, e, ed) {}, up(p, e, ed) {},   // p = {x, y} в пикселях картинки
    drawCursor(g, p, ed) {},                                  // рисовать курсор на экранном холсте
  });
})();
```

API редактора (`ed`): `img` (canvas картинки), `mask` (canvas выделения: белое = выделено),
`scale`, `offset`, `makeCanvas(w,h)`, `clone(c)`, `redraw()`,
`commit(newCanvas, 'сообщение', keepMask=true)` — применить с записью в историю (Ctrl+Z),
`applyMasked(resultCanvas, 'сообщение', feather)` — применить только в выделенной области,
`hasMask()`, `clearMask()`, `invertMask()`, `maskChanged()`, `maskDone()`,
`overlay = (g) => {…}` — дорисовка поверх (рамки, контуры), `preview = 'css-filter'` — живой предпросмотр,
`toast('текст', isError)`.
Готовые классы для панели: `ed-field`, `ed-row`, `ed-chips`, `ed-check`, `ed-swatches`, `btn`, `btn primary`.
Примеры: `tools/50-crop.js` (рамка + кнопки), `tools/70-adjust.js` (ползунки + выделение), `tools/60-transform.js` (действия).

## Как добавить ИИ-функцию (новый граф ComfyUI)

1. Граф — функция в `comfy.js` по образцу `wfEdit` / `wfUpscale` (формат API ComfyUI: `{id: {class_type, inputs}}`).
2. Модель — в `atelier.config.json` (имена как в папках моделей ComfyUI; `server.js → model()` сам найдёт файл).
3. Задание — в `server.js` по образцу `createUpscale` / `createEdit` + маршрут `/api/...`.
4. Кнопка — в `public/app.js` (`action()`), либо инструмент в `public/tools/`.
5. Новую модель добавить в `install.ps1` (`Need ...`) для обеих редакций, иначе у пользователей её не будет.
   Если модели нет — функция должна понятно сказать «запустите install.bat» или тихо перейти на запасной способ.

Готовые возможности (для ориентира): «Нарисовать по наброску / по контуру фото» (ControlNet, `job.control`),
«Раскрыть кадр» (`createOutpaint`), серии (несколько строк промпта = общий seed, `params.series`),
доски настроения (`/api/boards`), «Мой стиль» — обучение LoRA на картинах художника (`createTrain`, `/api/train`, `/api/loras`),
обмен стилями (`.artostyle`: `exportStyle` / `importStyle`), «Мой вкус» — ♡/👎 → мягкие образцы стиля (`tasteRefs`, `withTaste`).

## Смена моделей у пользователей

Меняете модель в `atelier.config.json` — пропишите `download` (откуда качать, если её нет) и добавьте старую в `retired`.
После обновления Arto сам докачает новое (`updateModels`, прогресс в статусе двигателя) и только потом удалит старое —
и только из папок `models/*/atelier/`, которые создаёт сам Arto. Файлы пользователя в других папках ComfyUI не трогать.

## Подсказки «Как пользоваться»

Меняете интерфейс (переименовали/переставили кнопку, добавили действие) — поправьте шаги в `public/tour.js` (`TOURS`):
`{ el: '#id', title, text, img, before }`. Иначе подсказка будет указывать в пустоту. Проверка: открыть «Как пользоваться» и пройти подсказку.

## Дизайн

- Все цвета — CSS-переменные в начале `public/style.css` (`--bg`, `--accent`, …). Новую тему делать через них.
- Тёмная «мастерская», акцент — тёплое золото. Шрифты системные (приложение офлайн — без Google Fonts/CDN).
- Техники (prompt.js STYLES) — честные: в core только материал, инструмент и основа; в avoid — чего в этой технике быть не может.
  Никаких «красивостей» про свет и цвет для графики. Проверять: один сюжет во всех техниках, каждая должна узнаваться.
- Тексты интерфейса: по-русски, просто, без жаргона («Ещё похожих», а не «Vary subtle»).

## Правила

- Никаких облачных сервисов и внешних CDN: приложение обязано работать без интернета.
- Не трогать `data/` (работы пользователя) и чужие файлы в папке ComfyUI.
- После правок: `node --check <файл>` для JS; запустить `start.bat` и проверить в браузере.
- Две редакции с ОДИНАКОВЫМИ возможностями, разница только в моделях:
  `pro` — SDXL + редактор Qwen-Image 2.1 turbo (`edit.kind: "qwen21"`); `lite` — SD 1.5 LCM + редактор FLUX.2 klein 4B (`edit.kind: "flux2"`).
  Новые функции делать для обеих редакций и проверять на обеих (переключение — `edition` в `data/local.json`).
